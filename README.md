# FYP OCR Benchmarking & AI Training Notebooks

This repository contains the Python Notebooks used for the FYP - Module 2 (Return Management).

## Contents
1. **Model Evaluation & Benchmarking:** Scripts used to calculate Character Error Rate (CER), Word Error Rate (WER), and Bag-of-Words Precision across various Vision Language Models (GLM-OCR, Qwen, LLaVA, Moondream).
2. **Signature Detection Training:** MobileNetV2 fine-tuning and data augmentation scripts for authorized signature classification.
3. **Cloudflare Colab Tunneling:** Scripts to host Ollama VLMs on Google Colab GPUs and securely tunnel them to a local FastAPI backend environment.

## Dataset Confidentiality Notice

Due to **Data Privacy and Non-Disclosure Agreements (NDA)** with our industry client, the raw image dataset of the physical Credit Note Requisition (CNR) forms is strictly confidential and **cannot be published publicly** in this repository.

* All automated evaluation code, test methodologies, and final mathematical benchmark metrics are preserved in these notebooks.
